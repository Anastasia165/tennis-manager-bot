# TennisManagerBot 🎾

Telegram бот для учета теннисных тренировок, отслеживания прогресса и управления финансами теннисного клуба.

**Переписано с использованием aiogram 3.x** - современного асинхронного фреймворка для Telegram Bot API.

## Возможности

- 📊 Учет статистики посещений тренировок
- 📈 Отслеживание прогресса и результатов
- 💰 Управление абонементами и бюджетом на тренировки
- 🎯 Аналитика тренировок за любой период (неделя, месяц, год, все время)
- 👥 Учет групповых и индивидуальных занятий
- 🔐 Управление профилем и истории тренировок
- 📞 Сохранение контактной информации

## Требования

- Python 3.9+
- pip или poetry для управления зависимостями

## Установка и запуск

### 1. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Создайте файл `.env` с конфигурацией:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321
DB_PATH=data/tennis_club.db
LOG_LEVEL=INFO
LOG_DIR=logs
```

Получить `BOT_TOKEN` можно у [@BotFather](https://t.me/botfather) в Telegram.

### 3. Запустите бота:
```bash
python bot.py
```

Бот запустится в режиме polling и будет готов к взаимодействию.

## Поток диалога (FSM - Finite State Machine)

### Регистрация новых пользователей:
1. `/start` → ввод имени → ввод фамилии → ввод телефона → регистрация завершена

### Создание абонемента:
1. `📝 Новый абонемент` → ввод номера → ввод суммы → абонемент создан

### Добавление тренировки:
1. `🎾 Добавить тренировку` → выбор продолжительности → выбор количества участников → выбор типа корта → ввод имени тренера → тренировка добавлена

### Просмотр статистики:
1. `📊 Статистика` → выбор периода (неделя/месяц/год/все время) → вывод статистики

## Команды бота

- `/start` - запуск бота / главное меню
- `🎾 Добавить тренировку` - добавить новую тренировку
- `💰 Баланс абонемента` - показать текущий баланс
- `📊 Статистика` - просмотр статистики за выбранный период
- `📝 Новый абонемент` - создать новый абонемент
- `📋 История тренировок` - последние 10 тренировок
- `👤 Профиль` - информация о профиле пользователя
- `❌ Отмена` - отмена текущей операции

## Миграция с python-telegram-bot на aiogram

**Основные изменения:**

### 1. **ConversationHandler → FSM (Finite State Machine)**
- Вместо числовых состояний теперь используются классы FSM со State объектами
- Более гибкий и масштабируемый подход

**Было:**
```python
config.STATES['REGISTER_FIRST_NAME']: 1
```

**Стало:**
```python
class RegisterStates(StatesGroup):
    first_name = State()
```

### 2. **Обработчики сообщений**
- Вместо функций с параметрами `update` и `context` теперь используются `message` и `state`
- Прямой доступ к объектам Telegram API

**Было:**
```python
async def start(self, update: Update, context: ContextTypes.DEFAULT_TYPE):
    user = update.effective_user
    await update.message.reply_text("...")
```

**Стало:**
```python
async def start(self, message: types.Message, state: FSMContext):
    user = message.from_user
    await message.answer("...")
```

### 3. **Диспетчер и фильтры**
- Использование декораторов `@dp.message()` с фильтрами `F`
- Более читаемый и явный код

**Было:**
```python
MessageHandler(filters.Regex('^🎾 Добавить тренировку$'), handlers.add_training_start)
```

**Стало:**
```python
@dp.message(F.text == '🎾 Добавить тренировку')
async def add_training_handler(message: types.Message, state):
```

### 4. **Асинхронный запуск**
- Полная асинхронность через `asyncio.run()`

**Было:**
```python
application.run_polling()
```

**Стало:**
```python
await dp.start_polling(bot)
```

## База данных

Структура таблиц в SQLite:

- **users** - профили пользователей
- **subscriptions** - абонементы с отслеживанием баланса
- **training_sessions** - тренировочные сессии
- **training_participants** - участники тренировок
- **price_list** - прайс-лист (60/90/120 мин, 1-4 участников)
- **transactions** - история транзакций

## Логирование

Логи сохраняются в директорию `logs/`:
- `tennis_bot.log` - общие логи (30 дней)
- `errors.log` - ошибки (90 дней)
- Ротация по дням (полночь)
